# Uruha Rushia (潤羽るしあ) — Fine-Art Monograph & Visual Archive

> A minimalist, editorial fine-art exhibition website celebrating the legacy, visual forms, and discography of Hololive 3rd Generation VTuber **Uruha Rushia**.

---

## ✨ Features

- **Tokyo Fine-Art Editorial Layout**: Clean editorial monograph aesthetic with paper-grain texture and balanced typography.
- **Synchronized 1:1 Theme Wipe**: Pure white beam runner sweeping across the viewport in sync with CSS `clip-path` via the View Transitions API.
- **Haute Couture Wardrobe Monolith**: Interactive 60fps expandable costume slabs showcasing her iconic eras (Debut 2019, Gothic 2020, Neko 2021).
- **Physical Collector's Vinyl (`Iris`)**: Interactive vinyl sleeve unit with concentric grooves, spindle hole, and hover 360-degree rotation animation.
- **Ultra-Minimal Navigation**: 4 dashes on the right margin tracking active sections and a top hairline scroll progress indicator.
- **Minimal Fullscreen Artwork Viewer**: Distraction-free high-resolution image inspection stage.

---

## 🚀 Getting Started

To run the project locally, serve the directory using any static file server:

```bash
# Using Python
python -m http.server 3000

# Using Node.js (serve)
npx serve .
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
